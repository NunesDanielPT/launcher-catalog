# ShowKit — novidades

## 0.1.5

- Doações: lista de apoiantes (por agora com nomes de exemplo, marcados como tal)

## 0.1.4

- As versões das apps deixam de ficar bloqueadas pelo limite de pedidos do GitHub: quando a API recusa, o ShowKit vai buscar a última versão diretamente às páginas do github.com (resolve "O GitHub limitou os pedidos" e o "Sem ligação" nas apps do ArtCraft)
- Pedidos repetidos à API do GitHub já não gastam o limite quando nada mudou
- Doações: MB WAY em modo de teste, com número de telemóvel, pedido e confirmação simulados (nenhum valor é cobrado); os outros métodos ficam como "brevemente"

## 0.1.3

- Novo separador **Doações**: explica que o projeto é open-source e precisa de apoio, com escolha de valor, frequência e forma de pagamento (temporariamente indisponível)
- Botões para pedir melhorias, reportar problemas e dar opinião sobre cada aplicação

## 0.1.2

- Nova secção **Softwares do ArtCraft**: as apps da ArtCraft (PhotoCraft, GridCraft, WordCraft, CADCraft, Craft Anything…) instalam-se e atualizam-se pelo ShowKit, separadas das apps de Daniel Nunes
- Instalação e desinstalação de pacotes MSI
- Menos pedidos à API do GitHub ao carregar várias vezes em atualizar
- Apps novas e alterações ao catálogo aparecem logo ao carregar em atualizar (antes podiam demorar até 5 minutos)

## 0.1.1

- As descrições das apps podem ter várias linhas (ex.: Projeção e LED wall no MapSim)

## 0.1.0

- Primeira versão do ShowKit / First ShowKit release
- Lista as apps de Daniel Nunes: VIDEOHOST PLAYER, PLAYERSLICE e MapSim
- Instala, atualiza, abre e desinstala cada app a partir dos Releases do GitHub
- Vista em grelha ou lista, pesquisa e ordenação
- Português e inglês, tema escuro e claro
- O próprio ShowKit avisa quando há versão nova e atualiza-se sozinho
